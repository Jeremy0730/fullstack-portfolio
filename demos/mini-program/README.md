# Northline 点单

微信小程序风格的商城演示，在浏览器中运行。商品、购物车、优惠券、地址和订单保存在本机，刷新后仍然保留。支付不跳转微信或支付宝，只把订单记为「制作中」。

## 运行

```bash
cd demos/mini-program
npm install
npm run dev
```

浏览器打开 http://localhost:5175 。宽屏会收成手机框，窄屏铺满。

## 功能

- 首页搜索、领券、进入商品
- 点单页按分类和关键字筛选
- 商品详情、评价、加入购物车
- 购物车改数量，结算时选地址、优惠券和支付方式
- 订单列表和详情，并可把状态往后推一档
- 我的：积分、优惠券、收货地址

## 技术

Vue 3、TypeScript、Vite、Pinia、Vue Router

当前为浏览器中的界面与交互演示，不含微信登录。上架时迁入 uni-app，并接入登录、支付与订单接口。
